# Classroom Commons 0.5.0 · 教师交付审查

本记录只覆盖实际查阅的教师文档、打包代码及发行资源，不代表新版界面、真实宿主或课堂验收已通过。新版浏览器结果与全量核验由总体验收记录另行确认。

## 发现与修复

1. **教程缺少两次确认的说明。** 原指南从“审阅”直接跳到“应用”，没有解释勾选草稿审阅确认，也没有说明替换当前课程的对话框。已在中英文、WorkBuddy 和豆包路径中补齐；首次载入示例或新课前，提示可先保存当前项目。
2. **首次 HTML 页的字体与工作台不统一。** 原页面只声明通用系统字体，中文没有明确回退顺序。已改为本地中文字体优先、保留阿语回退，统一灰绿底色、边框和按钮，提供窄屏与打印样式。未引入远程字体或资源；美观效果仍需单独视觉核验。
3. **教师备份与教学单需继续区分。** 保留“保存项目文件”用于继续编辑、“离线教学包”只读、“打开项目”恢复的说明，明确浏览器自动保存不能代替备份。新增活动条只读详情的用法说明；实际新交互仍待新版浏览器核验。
4. **不同构建的前端可能被装入两个入口。** 原打包脚本只检查独立 HTML 存在，没有比较 Skill 内的工作台。已添加打包前字节一致性检查，发现不一致时先停止，不生成 ZIP。此检查不代替最终版本与新构建验收。
5. **发行检查未遍历全部教程与本地引用。** 新增检查覆盖每份教师指南、HTML 相对链接与内嵌资源、源码 README 本地链接及图片，以及独立工作台与两种 Skill 包中的 HTML 一致性。

## 默认免费路径与可选接口

教师主路径仍是解压打开→选示例或新课→编辑、适配、排程→保存。AI 可选，普通聊天复制粘贴不要求 API。第三方要求购买或升级时停止起草，本机编辑和导出继续使用。

少数有经验者可自愿使用 AI 页底部折叠的自有 API 选项。文档说明默认关闭、只有主动点接口起草才请求自填服务、服务商可能收费、密钥不写入课程文件。新手教程开头不要求配置接口。该功能行为及密钥内存边界仍由对应实现测试和浏览器核验确认。
