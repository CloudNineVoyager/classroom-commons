# Classroom Commons 0.5.0 验收记录

日期：2026-10-22。以本机现有 0.4 源码发行快照固定审查起点；本轮目标是字体与界面美观优先、可靠性审查、低调且独立的可选 API。没有等待用户协助，没有调用真实收费服务或重试已取消的豆包实测。

## 实现与发现

| 发现 | 修复及验证 |
| --- | --- |
| 辅助文字小而偏浅，中文字体回退不明确 | 系统中文 / Latin / 阿语字体；正文 15px、输入 16px、导航 14px、辅助字至少 12px；实际浏览器读到中文回退和 13px 排程说明。 |
| 手机头部和工具栏过高，320px 导航与保存文案断字 | 品牌、状态与语言控件收紧，工具栏两列三行，纸张与打印成组；保留 44px 点击高度，320 / 390 / 768px 实际查看。 |
| 小时间块只能看到截断内容 | 点击或 Enter 打开只读详情，标题和目标完整换行；Esc 恢复触发按钮焦点，另有顺序列表。390px 实际从列表打开详情。 |
| 阿语导航词过长，详情 0–5 显示为 5–0 | 使用短导航标签，时间数值加 LTR 隔离；320px 复验截图显示 0–5，单位保留阿语方向。 |
| 成功延误重排后旧请求/草稿仍可能应用 | 统一使旧草稿失效；聚焦回归在原逻辑复现后通过。 |
| 新宿主请求仍在保存时可能接收旧回复 | 保存前先撤销旧请求身份；延迟保存回归通过。 |
| 恢复请求因 JSON 对象字段顺序不同被误判过时 | 对编辑内容规范化后比较；逻辑等价的恢复回归通过。 |
| 接口超时后晚到流仍可能成功，密钥首尾换行被 trim 掩盖 | 成功返回前再检查超时/取消；验证原始密钥中的换行；忽略 abort 的迟到流也只能失败。 |
| 教程遗漏草稿勾选与替换确认，可能把不同版本 HTML 装进包 | 教程补齐，打包前逐字节比较，差异时停止写包；独立回归验证。 |

配色公式抽查：正文对白 11.73:1、灰字 6.06:1、次灰 5.16:1、白字绿按钮 7.88:1、警告组合 6.41:1；输入边界对白 3.03:1、焦点对白 5.16:1。这是指定颜色组合检查，不是全站 WCAG 认证；参考标准见 [设计记录](ui-0.5.0-design.md)。

## 可选 API 的实际范围

- 默认不展开、不启用；无服务商默认值。免费本机编辑、材料适配、排程、保存、教学单以及普通聊天复制粘贴均不依赖 API。
- 明确说明服务商可能收费。密钥与配置仅在当前页面内存，不读取其他软件凭据，不写项目、教学单、宿主文件或浏览器存储。
- 仅主动点击接口起草才发一条请求，无自动重试/代理。使用 HTTPS 或指定本机 HTTP 地址，禁止地址认证、查询参数、重定向；不发环境 Cookie 或 referrer。
- 60 秒超时、1MB 响应上限；错误保留当前课程，取消/关闭/课程变化后拒绝迟到回复。返回仍需严格解析、人工核对勾选及替换确认。
- 使用本机 CORS 模拟服务和匿名示例，实际填写/启用时服务请求数为 0；点击后才出现 POST。测试有密钥及无密钥路径、503 失败和取消，未调用真实模型或消耗额度。
- 模拟服务只记录请求路径、模型、是否有认证、是否误将密钥放正文、消息数；有密钥请求的正文未含模拟密钥。刷新清空接口配置并关闭开关，保留正常课程和需求。
- 实际下载项目检查不含模拟密钥或接口地址。最终构建的接口回复先显示不同标题的草稿，而顶部当前课程仍为原课，证明没有自动替换。

## 本轮实际浏览器检查

- Windows Codex 内置浏览器，经本机 HTTP 运行独立构建和桥接入口；界面显示 v0.5.0。
- 两组、30 分钟、12 个活动生成通过约束检查的排程；实际下载 JSON 包含 12 项活动和 12 条排程，再选该下载文件导入、确认后依然为已检查排程。
- 点击 / Enter 打开活动目标、材料及前置说明，Esc 关闭回到原按钮。390px 顺序列表可用；只读详情不触发课程变更。
- 中、英、西、阿语实际切换，中文/西语/阿语视觉检查；中文与阿语 320px、中文 390px、768px 框架查看。框架高度 680px，属于布局验证，不等同于手机触摸设备。
- 教师指南桌面、390px 预览；起步四步均无 API。桌面无横向溢出，读取 body clientWidth 与 scrollWidth 均为 1265px。
- 最后课程恢复后读取浏览器 warn/error 为空。此前测试服务返回 503 属于主动失败用例。
- 旧开发预览 4173 本轮被浏览器客户端阻止，没有重试或改变设置；使用此前已运行并完成测试的桥接入口与既有布局框架继续验收。未以其他机制绕过 file 或第三方宿主的限制。
