# Classroom Commons 0.3.0 · 试用版交付核验

本轮四小时目标开始于 **2026-10-22 07:14:31 UTC**，截止 **11:14:31 UTC**。目标为交付无需 API、无需购买服务的独立教师试用包；豆包网页实测按用户指令跳过，不能真实验收的宿主标明限制。未购买服务、调用外部模型或改动系统网络、安全设置。

## 实质改动

- 有合法较晚开始安排的课程，现在能找到通过注意力间隔检查的排程；损坏排程不再使恢复崩溃。
- 保存课程同时保存已检查排程；未完成学习组、清空的字段仍可保存并继续修改。AI 草稿继续使用严格验证，未完成内容不会被标为排程通过。
- 宿主桥接将完整课程原子保存到 `course.json`，重启换端口仍可恢复排程；复制文件夹后不会误连接原目录。损坏文件保留原件并报告错误。
- 宿主首次打开不会把其他课程的浏览器缓存自动写进新目录，快速编辑的保存按顺序发送。
- 聊天回复兼容说明文字、代码块和外层 `project` 包装；有多个课程、截断或超限时要求修正，不让老师改代码。
- 一页 HTML 教师教程、中英文完整示例课程、教学单、通用 Skill、WorkBuddy 专用包、源码 ZIP 和 SHA256 清单。
- 阿拉伯语界面可从右到左排列，时间范围保持 `0–10` 顺序，时间轴端点不再裁掉首位。

## 已实际完成的界面流程

均在本机浏览器通过 loopback HTTP 操作，使用匿名示例：

1. 新增尚无活动的第三个学习组，刷新后仍存在。
2. 点击“保存项目文件”实际下载，再通过“打开项目”的文件选择入口导入，第三个组恢复。
3. 审阅并采用缺少练习纸的替代活动，生成六项活动的完整排程。
4. 实际下载含六项排程的课程文件和离线教学单；文件再次校验无排程问题，教学单无脚本。
5. 修改标题后导入已下载课程，标题和“已通过约束检查”的六项排程均恢复。
6. 宿主工作台导入完整课程，确认磁盘 `course.json` 有六项排程；停止服务、换新端口启动后，浏览器仍显示六项已检查排程。
7. 切换阿拉伯语确认 `dir=rtl`，排程时间范围的 `dir=ltr`、文字为 `0–10`；视觉检查时间轴端点完整。
8. 打印入口生成了包含完整排程与活动的 `about:srcdoc` 教学页，浏览器无错误；未完成操作系统“保存 PDF”或实体打印。
9. 在工作台提交一份新的 30 分钟口语故事课需求，由当前 Codex 会话读取请求、按 Skill 流程实际起草并回传。工作台显示十二项活动、准确报告零纸卡的缺口；审阅应用并确认演示用替代方案后，十二项排程通过检查，课程文件和教学单实际下载，收入示例目录。这证明当前会话的起草交付流程，不代表某个第三方免费账号已验收。

实际下载的测试文件副本位于 `.qa/verified-draft.json`、`.qa/verified-course.json`、`.qa/verified-handout.html`，不收入开源源码包。

- `python -X utf8 -m unittest discover -s test -p 'test_*.py'`：**20 项通过**，含服务停止重启、损坏文件保留、复制目录隔离、解压安装包的零依赖请求/草稿往返、发行 ZIP 与 SHA256 清单。
- 通用 Skill 的 `quick_validate.py`：通过（UTF-8 模式）。
- 将最终源码 ZIP 解压到 `.qa/final-source-rebuild/classroom-commons`，未安装 npm/pip 依赖，重新构建后 **24 项 Node 测试和 20 项 Python 测试再次全部通过**。
- 四种界面语言均在浏览器中实际切换；中文、英文、西班牙语为 LTR，阿拉伯语为 RTL。并未以此代替母语译文审阅。
- 实际课程下载文件已改为包含课名，并成功下载 `Classroom-石子里的故事：先后顺序与原因.json`，避免多节课都使用同名备份。
- 最终产物及字节数、SHA256 见 `releases/release-manifest.json`。源码包排除 `.qa`、`node_modules`、`.git` 和运行时会话文件。

排程另与独立整数时间枚举比对了 100 个小课例：88 个可行、12 个不可行，零分歧；返回排程再次校验均通过。

维护清理备注：自动审批审核拒绝删除旧 `node_modules`，仅返回 `blocked by policy`。目录已保留，源码与教师交付 ZIP 都排除该目录；独立源码重建不使用它。

## 明确保留的边界

- WorkBuddy 5.8.3 的窗口可以读取导航文字，但截图捕获一直超时。本轮尝试其公开的窗口 Raise 操作后仍超时，未安装 Skill、未发起真实课程请求，不能宣称免费账号实测通过。专用 ZIP 解压后的零依赖桥接流程已测试，二者不是同一验收等级。
- 豆包普通聊天实测由用户要求跳过；教程为通用用法，不代表真实账号往返已完成。豆包工作与普通聊天不可混用权益判断。
- 当前浏览器工具拒绝 `file://`，未绕过限制；直接双击离线 HTML、物理断网、手机、macOS/Linux 和实体打印尚未实际验收。同一单文件 HTML 已通过 HTTP 浏览器和代码/CSP核验；它不获取远程代码、字体或模型服务。
- 四种界面语言通过键值完整性检查，尚需母语教师审阅。真实乡村课堂易用性和教学效果仍待教师试用。
- 资源检查表示同时可用容量，不是耗材累计预算；空白时间由老师安排常规活动；有界排程搜索可能返回 unknown。

交付等级：可运行、可保存恢复、可导出、可供教师试用的工程版本。不是已完成所有宿主和课堂验收的正式教育产品。
