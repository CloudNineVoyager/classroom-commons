# 0.5 设计目标与验收范围

优先级：界面美观与阅读舒适度，其次是使用过程可靠性。自有 API 是少数用户的折叠高级功能，不成为备课前提。

## 字体与视觉

- 使用离线系统字体回退，分别照顾中文、拉丁文字和阿语；不声明不存在的网页字体已经加载，不添加远程字体请求。
- 正文约 15px、输入 16px、按钮和导航约 14px，辅助内容至少 12px；使用清楚的 400 / 600 字重、舒展行距和稳定的标题层级。
- 用更深的次要文字颜色替代原先大量浅灰字；卡片、分隔线、主操作、状态及焦点保持统一。桌面紧凑而不拥挤，手机自然换行。
- 时间线保留真实时间比例。活动可点击或键盘打开完整只读详情，并提供列表入口，避免手机只能看截断标题。

普通文字对比度以 [W3C 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) 的 4.5:1 为抽查目标；布局扩至 320 / 390 / 768 像素检查，参考 [W3C 重排说明](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)。字体尺寸属于本项目设计选择，不是 WCAG 强制字号。抽查不等于完整无障碍认证。

## 成品审查

从当前 0.4 发行源码固定快照审查教师路径、保存恢复、异步草稿、课程替换和发行一致性。仅修证据明确的问题，并以实际源码回归验证。默认免费离线备课、宿主和普通聊天复制粘贴路径继续独立可用。

## 可选 API

- AI 页末尾默认折叠，默认关闭；没有预设服务商、自动探测、自动请求、失败重试或付费回退。
- 教师自行输入完整兼容 Chat Completions 地址、模型和可选密钥。配置仅在当前页面内存中；课程文件、浏览器保存、宿主文件和教学单不携带密钥。
- 只有主动点起草才将当前匿名课程及需求发送到填写的服务。明确该服务可能收费；取消不代表服务商一定不计费。
- 使用 HTTPS，或本机 HTTP；禁止地址内嵌认证/查询密钥和自动重定向，省略环境 Cookie 与 referrer。60 秒超时、1MB 响应上限，取消和课程变化后忽略旧结果。
- 返回内容仍走严格解析、教师审阅和替换确认。网络、额度、跨域或回复错误保留原课程，并继续提供普通聊天方式。

兼容请求形态参照 [Chat Completions 参考](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)：`model`、`messages`、非流式回复及 Bearer 认证。此实现不代表所有服务或模型均支持；浏览器跨域权限由服务端决定。

本机测试使用模拟兼容接口，不使用真实密钥、不购买额度。真实服务、账号、设备、译文和课堂效果仍分别验收。
