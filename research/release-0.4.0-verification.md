# Classroom Commons 0.4.0 · 界面重做核验

记录日期：2026-10-22。本记录区分实际运行结果和真实账号、设备、课堂验收。

## 范围

按用户要求，用 React、源码内维护的统一组件、Lucide 图标和 Radix 对话框重做界面，统一视觉和操作语言，精简实际安装的依赖。保留确定性的资源检查和排程、本机课程保存恢复、Skill 本地桥接以及普通 AI 复制粘贴。

教师继续使用发行包里的单文件 HTML，不需要安装构建依赖、Python 或 API。开发者源码重建需 Node 22+ 并运行 `npm ci`，按锁文件安装 React、ReactDOM、Lucide、Radix Dialog 和构建工具 esbuild；0.3 的“无 npm 安装重建”结果不适用于新版。`npm start` 先构建再预览，`npm run preview` 只预览现有构建。完整授权已嵌入 HTML，并随发行 ZIP 附带 `THIRD_PARTY_NOTICES.txt`。

## 本轮具体修复

- 统一源控 Button / Card / Field / Dialog，Lucide 图标，React 视图；移除已不用的原始网页入口和 Service Worker，开发预览直接使用同一发行 HTML。
- 新建和替换确认、真实保存状态、AI 需求/回复恢复及工作区隔离；先显示有材料缺口的活动。
- 普通重新求解、延误、Worker 超时/错误均保留仍有效的原排程，并明确提示保留；课程条件修改后取消待处理旧请求。
- 导入和自动恢复损坏排程时提示重新排程；AI 输入专用解析移除模型伪造的教师确认，合法课程的真实确认记录仍可往返。
- 移动表单输入 14px，主按钮 13px，提示不小于 11px，移动主要触摸控件至少 44px；阿语时间范围单独采用 LTR，时间轴首尾刻度贴边。
- Windows 原子替换遇到短暂共享冲突时最多重试约 1 秒，其他错误仍返回失败并保留旧文件；生产版没有新增日志或依赖。

独立回归最初有一次复制会话启动失败，其子进程错误当时被丢弃。之后保留读取句柄可稳定复现同一启动路径的 `WinError 5`，修复前失败、修复后通过；24 次自然复测未重现原偶发，不能百分百确定第一次失败也是同一原因。最终完整回归通过，不把“重跑成功”当作问题定位的证据。

## 教师教程准备

一页 HTML 入口将教师路径简化为四步：选课→修改→检查→保存。AI 为可选的写需求、复制发送、粘回审阅三步。包含回复修正、付费不购买、保存项目与只读教学单区别，以及下次打开备份的方法。教程只使用静态 HTML 和内嵌样式，不引入脚本或远程资源。

中文教程 17 个界面名称、14 个文档相对链接已核对；西班牙语和阿语各 16 个按钮名称与字典一致。新增对应快速指南与 HTML 折叠说明，阿语设置 RTL。README 区分开发依赖与教师安装步骤。

## 当前保留的验收边界

- WorkBuddy 5.8.3 窗口捕获失败；真实免费账号的安装、课程请求及返回尚未完成。专用包格式或开发桥接通过不等于宿主验收。
- 豆包普通聊天网页实测按用户要求跳过，不请求用户关闭弹窗，不绕过阻碍。普通聊天和豆包工作不混用权益与能力判断。
- 此前当前 Codex 会话的匿名课例起草不证明第三方免费额度可用。免费额度、地区可用性和收费政策由第三方决定。
- 先前浏览器工具拒绝 `file://`；未绕过。直接双击、物理断网、真实手机、macOS/Linux、系统保存 PDF、实体打印及母语译文仍须分别验收；浏览器窄框架检查不替代这些设备验收。
- 真实乡村教师试用和课堂效果未验收。界面全球适配不代表全部国家、宿主或课堂均已验证。
- 有界排程搜索可能返回“本次未找到”，不构成无解证明；资源表示同时容量，空白时段仍由老师安排常规活动。
