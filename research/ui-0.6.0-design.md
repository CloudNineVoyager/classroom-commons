# 0.6 原创备课册设计目标

以乡村教师的日常备课为中心，保留现有离线备课、资源检查、排程和可选 AI 流程。用户明确指出：其他仓库只是审美参考，不能照抄具体视觉或脱离教师场景。

## 目标与验收

1. 首页展示教师当前课程：实际课程名、时长、分组和各组首个活动。用备课册的版式组织内容，暖白纸面、墨色文字、苔绿操作和少量陶土细节；不使用科技星场或第三方媒体。
2. 主次清楚：先“开始备课”和“打开项目”，再看当前备课册和四个工具入口；新建、示例、保存放在下方操作区。保留顶栏五入口，进入页面后聚焦主内容。
3. 功能页与首页使用同一套字体、颜色、边界和焦点语言。输入至少 16px；中文、英文、西班牙语与阿拉伯语可读，RTL 保持排程时间的方向语义。
4. 桌面实际截图评估排版、留白和内容密度；320 / 390 / 768 像素框架实看操作区无横向溢出。窄框架不代替实体设备验收。
5. 单文件内嵌代码、样式和本项目原创 SVG 标志，无远程字体、组件或图片。只使用现有 React、Lucide、Radix，不引入额外运行依赖。
6. 本地编辑、检查、排程、导入导出保持免费。API 保留在 AI 页底部折叠区，默认关闭、无预设服务、只在主动操作后请求。
7. 发行物只含原创 MIT 代码和声明完整的既有依赖，不包含参考仓库代码或媒体。废弃的科幻草稿不作为发布成果。

最终验证见 release-0.6.0-verification.md。旧 0.5 记录作为历史保留；宿主真实账号、实体设备和课堂试用仍属独立验收。
