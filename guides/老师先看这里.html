CLASSROOM COMMONS · 教师指南

备一节课，从这里开始

把课堂留给教与学。先解压工具包，再打开工作台；免费备课，无需安装或填写密钥。

打开备课工作台 →

按钮打不开？在解压后的同一文件夹里，双击 Classroom-Commons.html。打开后可在右上角选择“简体中文”。

备课只需四步

  1. 选一节课。打开后先到“首页”。第一次可在首页下方点“载入示例”；有备份点“打开项目”，从头写点“新建课程”。点“开始备课”进入“我的课堂”。出现替换提示时，想保留当前课就先点“先保存当前项目”，再确认替换。
  2. 按自己的课堂修改。“我的课堂”填分组、时间、阅读条件和手头材料；“课堂排程”里可改活动、时长，也可“添加活动”。
  3. 检查安排。先看“资源适配”，替代活动适合学生才确认采用。再到“课堂排程”点“生成课堂排程”，按提示调整。空白时间仍需你安排常规活动。
  4. 保存。点“保存项目文件”留备份。带进教室的教学单选“离线教学包”，需要打印选“打印 / PDF”。

这些操作在本机完成，不调用 AI。示例故意没有练习纸，帮助你试用材料不足时的替代方案。学习组的阅读能力和最长无老师指导时间，由你按课堂实际填写。

排程里的活动条可以点开查看目标和材料；想修改活动，请回到下方的“教学活动”。

顶栏和首页四个编号模块都能进入“我的课堂”“课堂排程”“资源适配”“AI 助手”。随时点顶栏“首页”回来；课程卡可继续编辑；保存当前课程用首页下方的“保存项目文件”。

想请已有的免费 AI 帮忙？可选三步

  1. 写需求。工作台点“AI 助手”，说清主题、学习目标和限制。例如：
帮我准备数的组成课，保留当前分组、40 分钟和材料数量，不增加材料。
  1. 发给 AI。点“复制需求给 AI 助手”，打开已有的豆包、WorkBuddy 或其他 AI，新建普通对话，粘贴并发送。不用安装技能。
  2. 粘回回复。等 AI 完整回复，复制整条回复，回工作台粘贴，点“审阅粘贴的结果”。核对分组、目标、活动和材料，勾选确认后点“应用已审阅草稿”，再确认替换课程，检查资源和排程。

回复读不出来？点“复制修正请求，再发给 AI”，发回刚才的同一个对话，再粘回新的完整回复。不用自己改代码。

遇到购买、升级或额度不足：先停下，不买。
已有课程仍可在工作台编辑、检查、保存和导出。AI 平台的免费额度由平台决定。这里的普通聊天方法不要求开通“豆包工作”。

下次怎样接着改？

保留本工具包和刚才保存的课程备份（文件名以 Classroom- 开头，带有这节课的名字）。下次打开原工作台，点“打开项目”，选择这个备份文件。不要改文件里的内容。“离线教学包”是给课堂看的教学单，不能用来继续编辑。

工具包里还有哪些示例？

“示例课程”文件夹有中文数学课 maths-zh.course.json、英文数学课 maths-en.course.json，以及 30 分钟口语故事课 story-zh.course.json。在工作台点“打开项目”即可载入。相应教学单可直接打开查看。都是演示课程，实际使用仍由老师核对。

已经安装了课堂共作技能？

对助手说：“打开课堂共作工作台。”在已连接的工作台填写需求，点“把需求交给 AI 助手”，再回聊天说：“按工作台里的需求备课。”返回工作台审阅结果。没有打开时，直接使用上面的普通聊天三步法，无需自己装开发工具。

已有自己的 API 服务？可选高级功能

少数熟悉 API 的老师可自愿使用 AI 页底部折叠的高级选项。默认关闭，只有主动点 API 起草才发给自填服务，服务商可能收费；密钥不保存进课程文件。第一次使用请直接走前面的免费本机或普通聊天方法，不需要配置这里。

English: open, edit, check, save

Extract the toolkit, then open the workbench above and choose English. The home page opens first. Use Load example near the bottom, open a saved project, or start a new lesson. The main preparation button opens Classroom; the four numbered home modules and top navigation also open the editing sections. Edit groups, time and materials under Classroom, and activities under Lesson flow. Review Resource fit, confirm suitable alternatives, then build Lesson flow. Save project keeps an editable backup. Offline lesson is a handout for viewing.

Optional AI: describe your lesson under AI assistant; copy the request to an existing free chat; paste its complete reply back and review before applying. If unreadable, use the repair-request button. If asked to pay, stop drafting; local editing and export remain available. No API key or Skill installation is required.

To resume, open the original workbench and use Open project to load your saved course file (its name starts with Classroom- and includes the lesson title).

Español: elegir, editar, comprobar y guardar
  1. Descomprime el paquete y abre el espacio con el botón de arriba. Elige Español. Se abre la página de inicio: pulsa Cargar ejemplo en la parte inferior de inicio, abre un proyecto guardado o empieza con Nueva clase. El botón principal abre Mi aula; la navegación superior y los cuatro módulos numerados abren las demás secciones.
  2. Edita grupos, tiempo y materiales en Mi aula; actividades en Secuencia.
  3. Revisa Recursos, confirma solo alternativas adecuadas y pulsa Crear secuencia. Tú organizas los huecos.
  4. Guardar proyecto conserva una copia editable; Clase sin conexión es una hoja para consultar. Otro día, usa Abrir proyecto con el archivo guardado.

IA opcional: en Asistente de IA, describe la clase, pulsa Copiar petición para mi asistente y envíala a un chat gratuito que ya utilices. Pega el resultado completo y pulsa Revisar resultado pegado. Revisa y confirma antes de aplicarlo. Si no se lee, usa Copiar petición para corregir la respuesta en el mismo chat.

Si te piden pagar, detén la redacción sin comprar. La edición y exportación locales siguen disponibles. La traducción espera revisión de docentes hablantes nativos; las cuentas gratuitas reales de WorkBuddy y Doubao no están verificadas.

العربية: اختر وعدّل وافحص واحفظ
  1. فك ضغط الحزمة وافتح مساحة العمل بالزر أعلاه، ثم اختر العربية. تظهر الصفحة الرئيسية أولًا: اضغط تحميل مثال أسفل الصفحة الرئيسية، أو افتح مشروعًا محفوظًا، أو ابدأ مع درس جديد. ينقلك زر الإعداد الرئيسي إلى صفي، وتفتح الوحدات الأربع المرقمة وشريط التنقل العلوي بقية الأقسام.
  2. عدّل المجموعات والوقت والمواد في صفي، والأنشطة في تسلسل الدرس.
  3. راجع الموارد وأكّد البدائل المناسبة فقط، ثم اضغط إنشاء تسلسل الدرس. اختر نشاطًا اعتياديًا للفترات الفارغة.
  4. حفظ المشروع يحتفظ بنسخة قابلة للتعديل؛ حزمة دون اتصال ورقة للعرض. للمتابعة لاحقًا، استخدم فتح مشروع مع ملفك المحفوظ.

الذكاء الاصطناعي اختياري: صف الدرس في مساعد الذكاء الاصطناعي، واضغط نسخ الطلب للمساعد وأرسله في محادثة مجانية تستخدمها بالفعل. الصق الرد كاملًا واضغط مراجعة النتيجة الملصقة، ثم راجع وأكّد قبل التطبيق. إذا تعذرت قراءته، استخدم نسخ طلب لتصحيح الرد في المحادثة نفسها.

إذا طُلب الدفع، أوقف الصياغة دون شراء؛ يظل التحرير والتصدير المحلي متاحًا. تنتظر الترجمة مراجعة معلمين ناطقين بالعربية، ولم يُتحقق من الاستخدام الفعلي بحساب مجاني في WorkBuddy أو Doubao.

试用版：WorkBuddy、豆包的真实免费账号往返和教师试用尚未验收。请先用示例熟悉流程。只填匿名学习组，不填学生姓名或家庭信息；AI 内容和活动适用性由老师把关。浏览器自动保存不能代替项目备份。
