# Classroom Commons: start here

This toolkit is free. No account, payment or API key is needed for local planning. Extract the toolkit before opening its files. Real free-account round trips in WorkBuddy and Doubao, and teacher trials, are not yet accepted.

1. **Choose a lesson.** Open **Classroom-Commons.html** to reach the home page and choose a language. Use Load example near the bottom, use **Open project** for a saved backup, or start a new lesson. The main preparation button takes you to **Classroom**. If a replacement dialog appears, use **Save current project first** to keep the existing lesson before confirming replacement.
2. **Edit.** Enter groups, lesson length and materials under **Classroom**. Edit or add activities under **Lesson flow**. Set reading abilities and time without teacher contact from your own classroom knowledge.
3. **Check.** Review **Resource fit**, confirm alternatives only if suitable, then build **Lesson flow**. Follow any adjustment messages. Blank time still needs an appropriate routine.
4. **Save.** Use **Save project** for an editable backup. **Offline lesson** is a handout for viewing; **Print / PDF** opens the print flow. Keep the original workbench file.

These steps run locally without AI. Back up important projects using **Save project**. To resume later, open the original workbench, choose **Open project** and select your saved course file, whose name starts with **Classroom-** and includes the lesson title. You do not need to edit that file. Handouts cannot be used to resume editing.

Select an activity on the timeline to view its objective and materials. To change the activity, use the activity editor below the timeline.

The top navigation and four numbered home modules open Classroom, Lesson flow, Resource fit and AI assistant. Return home at any time from the top navigation. The current-lesson card opens the lesson for editing. Use Save project near the bottom to keep a backup.

For optional drafting, describe the class under **AI assistant**, copy the request to an existing free chat in an assistant you already use, then paste its complete response into the workbench. Review groups, objectives, activities and materials, tick the confirmation, then apply and confirm replacement. No Skill installation is required. If the response cannot be read, use **Copy a request to fix the reply**, send it to the same chat, then paste the new complete reply back. You do not need to edit its technical format.

If your host has this Skill installed, ask it to open Classroom Commons. After saving a request in the connected workbench, return to chat and ask the host to prepare the lesson. The page does not wake the assistant automatically.

If asked to buy, upgrade or add credits, stop AI drafting without paying. Third-party free AI allowances are controlled by each provider. Your existing lessons remain editable and exportable without paying us. Use anonymous group labels, and review AI content yourself. Passing scheduling checks does not prove educational effectiveness.
